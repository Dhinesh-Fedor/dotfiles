# My Dotfiles

My personal dotfiles for my Arch Linux setup.

Built around [Caelestia](https://github.com/caelestia-dots/caelestia), with a bunch of changes and tweaks I've made over time to fit the way I use my system.

## What's in here

- Hyprland
- Caelestia / Quickshell
- Fish
- Foot
- GTK / Qt theming
- Waypaper
- Fuzzel
- Thunar
- Custom scripts
- Various Wayland utilities and tweaks

## My setup

The base is Caelestia, but I've changed quite a few things from the original setup.

Some of the stuff I've customized:

- Hyprland keybinds, animations and window rules
- Gaps, borders, rounding, blur and opacity
- Workspace and floating window behavior
- Touchpad gestures
- Caelestia shell settings
- Launcher and status bar
- GTK / Qt themes and colors
- Cursor and icons
- Terminal and shell
- Default applications
- Wallpaper setup
- Screenshot workflow
- Small scripts and quality-of-life tweaks

There's also some stuff I've added myself, like the screenshot script and a custom floating-window toggle.

This isn't meant to be a clean Caelestia fork or an exact copy of the upstream setup. It's just Caelestia after I've messed around with it enough to make it mine.

## Notes

These dotfiles are very much a work in progress.

I change things whenever I feel like it — sometimes because I want to try something new, sometimes because I find a better way to do something, and sometimes just because I got bored of the current setup.

So this repo will probably keep changing with me.
